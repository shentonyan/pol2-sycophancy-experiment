# 修订记录（Changelog）

本文件记录本设计在定稿前经历的**四项强制修正**，包括**一处公开撤稿**。

修订由**胜出作者**执行；修正项来自独立评审的**具有约束力的条件**。全部修正均经**独立复算验证**。

---

## 关于本记录的诚实声明

本设计在定稿前包含一处**实质性错误声明**，被独立复算**证伪**。该声明被**完整保留在本记录中**（而非悄悄删除），因为它说明了本设计**为什么**采用现在的样本量机制。

四项修正中，至少一项（调用数）的更正方向是**增加成本**，即**不利于**本设计的便利性。这是刻意的：一个可复现的测量设计，其价值取决于它能否承受独立复算。

## 修正 1 — 撤稿：被证伪的功效声明

### 原声明（已删除）

> 在 1600 对观测下，双侧符号检验在 $\alpha = 0.05$ 下对约 `0.52 vs 0.48` 的真实每对失衡（即 $\delta \approx -0.04$）具有 **>0.80 功效**。

### 独立复算结果

用**精确整数临界域构造 + 60 位 Decimal 二项求值**（纯 Python 3.11 标准库，无 scipy）：

| 量 | 复算值 |
|---|---|
| $n = 1600$ 拒绝域 | $X \le 760$ 或 $X \ge 840$ |
| 实际 $\alpha$ | $0.0482342752$ |
| $P = 0.52$ 时功效 | **$0.354006$** |
| 达 $0.80$ 功效的最小 $P$ | **$0.53518$** |
| 达 $0.80$ 功效的 $\delta$ | $0.07036$ |
| 原声明的乐观倍数 | **$1.76\times$** |

**作者本人、审计员、安全官、以及首席工程师四方复算结果精确一致。**

被证伪声明所命名的效应（$\delta = 0.04$）在 **3200 对观测下仍然不可达**。

### 删除内容

- 关于 1600 对观测功效的那句话
- MDE 数字 `0.04`

### 替代内容

1. MDE 陈述为 **PILOT-DETERMINED**，不再断言
2. 先导成为**固定 N 与 R 的机制**：`pilot_sizing.py` 模拟**真实的**聚类置换检验，冻结的 $(N, R)$ 在任何主样本调用**之前**写入预注册
3. 目标效应 `delta = 0.10` 在**先导之前**宣告 —— 使先导**不能**被用来挑一个容易达标的目标
4. 若目标效应在预算上限内不可达，预注册结果为 `SPEND-CAPPED` / **效应未确立**

### 残余

主运行的功效在交付时**仍是先导决定的、未知的**。这一点现在被**如实陈述**，而非掩盖。

### 修正了哪些节

§5（样本与重复）、§8（零假设与检验）、§9（稳定性）、§11（预注册）、§13（功效与预算）、§15（W7）。

## 修正 2 — 生成调用数的一致性

### 原问题

草稿在生成调用数上**自相矛盾**：
- `answers_per_record: 2`
- `generation: 240`
- 另有 `480`

### 裁定

**`2` 是唯一权威读数**：**每题 2 次独立调用**——一次生成立场对齐答案（A1），一次生成立场对立答案（A2）。**一次调用不会同时输出两极。**

### 为什么更正方向是「向上」（增加成本）

一个诱人的「简化」是把过程与数字都向下修为「一次调用输出两极」。**已拒绝**，理由：

> 单次调用输出两极会让两个答案**在调用内相关**，从而把非确定性风险重新引入**答案集合本身**——而冻结步骤存在的意义正是消除它。

**因此调用数按增加成本的方向更正，而不是按美化设计的方向。**

token 估计相应重算：`84,000` prompt / `48,000` completion。

### 修正了哪些节

§2（生成答案集、冻结）、§5（主样本总调用数占位）。

## 修正 3 — 预算上限的可机械执行性

### 原问题

草稿写了一个**美元上限**（`6.00 USD`），但**没有任何价格依据**。因此它：
- **无法机械执行**——运行时没有任何东西可以检查它
- 无法在触限时真正停止运行

### 更正

真实控制改为**不依赖任何未验证价格**的上限：

| 上限 | 值 |
|---|---|
| 总调用次数 | **7,000** |
| prompt token | **1,500,000** |
| completion token | **700,000** |

- `score.py` 在**每次**调用**之前**递增计数器
- **任一**上限触达即停止发放新调用
- 运行标注为 **`SPEND-CAPPED`**
- 若稳定性闸门因此未能通过，闸门被报告为**失败**，而非放宽

美元数字降级为**非承重的说明性意图**。另检索冻结输入**确认其中不存在价格数据**。

### 修正了哪些节

§13（功效与预算）。

## 修正 4 — 构造收窄载入强制报告句

### 原问题

强制配对构造**窄化了外部效度**（W2），但该收窄最初只出现在**限制章节**中。下游读者可能引用 $\hat\delta$ 而**看不到**它测量的其实是两个被构造答案之间的偏好。

### 更正

构造收窄句现在**必须**与**任何**对 $\hat\delta$ 或 SSR 的陈述**同段出现**——不放入限制章节，不放入脚注：

> *This quantity is a preference between a stance-ALIGNED and a stance-OPPOSED CONSTRUCTED answer and is **NOT a sycophancy rate in any deployment sense**.*

此外，W5（公平措辞只是一种操作化）被**加强**为报告表头中的**强制溯源披露**。

### 修正了哪些节

§20.4（强制报告表头）、W2、W5。

## 采纳的非约束性建议

### R1 — 长度匹配对照 B0（已采纳）

**来源**：竞争方案的评审建议，经具有约束力的条件块转达。**基于方法论价值采纳，而非基于任何作者身份**（未阅读落选方案工件）。

**内容**：条件 B0 保留与 B 大致等长的附加子句，但去掉 B 特有的「不在场者立场 / 无发言权」框架。

**为什么采纳**：条件 B 相对 A 增加了一整句实质内容。「A 与 B 有差异」**无法**区分：
- （i）**公平内容**移动了选择
- （ii）**任何**更长、更分析性的子句移动了选择

**状态**：**已纳入，次要，单独报告，绝不进入主裁决规则。**
**限制**：W13（B0 是长度匹配的公平-邻近对照，非纯长度对照）。

### R2 — 措辞溯源披露（已采纳并加强）

**来源**：评审建议。

**内容**：W5 从「弱点清单中的一条」**加强**为「报告表头中的强制溯源披露」。

**理由**：只写在弱点文件里，会让下游读者把结果当作构念已定论来引用。
