# 证据对照表：每个设计选择的依据

本表回答一个问题：**这个选择是文献支持的，还是我们自己定的？**

依据类型只有四种：

- **文献**：有已核验的外部来源，且来源**确实说了**这一点（见 [references.md](references.md)）。
- **理论文本**：来自 PoL2 固定 commit 的原文（编号 A1）。
- **待先导实测**：数值要由先导实验导出，现在没有数。
- **自定**：本仓库作者的设计决定，**没有外部依据**。理由写在备注里，欢迎质疑。

表里「来源说了什么」只写**核验过的内容**；对只核验了题录的文献，只引用其摘要。

## 1. 问题与理论

| 设计选择 | 依据类型 | 来源与边界 |
|---|---|---|
| 把「爱＝公共性、恨＝排他性私有」作为理论动机 | 理论文本 | A1：§1.1「它不具私有属性，亦无阵营之分……爱本身即具有普适的公共性」；§1.2「恨的核心属性是排他性私有和暴力崇拜」。逐字引文与对应见 [theory-grounding.md](theory-grounding.md)。 |
| 把该对立操作化为「是否纳入不在场第三方」 | 自定 | PoL2 原文**没有**规定这一操作化；A1 §5.1 自述只给出框架与原则，细节留待工程。本操作化是**一种**选择，不是理论的唯一读法，也**不验证或证伪** PoL2。 |
| 「不在场」一词的借用 | 自定（已声明） | A1 §5.3.2 的「不在场」指因干扰而未产生情感体验的状态，与本实验的「不在场第三方」**不是同一概念**。本实验只借用词面。 |

## 2. 数据与结构

| 设计选择 | 依据类型 | 来源与边界 |
|---|---|---|
| 用 anthropics/evals 的三个 sycophancy 文件 | 文献 | B1、B2。B1 摘要写明该工作构造了 154 个数据集，并观察到更大的模型表现出更多 sycophancy。 |
| 「谄媚」是答案相对用户立场的属性，因此分析单元是生成的答案而不是数据集标签 | 自定 | 数据集每条只有一个标签（已用本地文件核对）。这是对本问题的推理，不是文献结论。 |
| 为每条记录生成一个立场对齐答案与一个立场对立答案 | 自定 | 目的：保证两极都有，避免自由生成时两个条件都接近零方差。 |
| 回答与用户观点一致时更可能被偏好，所以「选对齐答案」是值得测的行为 | 文献 | C1 摘要：「当回答与用户观点一致时，更容易被偏好」。边界：C1 研究的是人类与偏好模型，不是本实验的评分模型。 |
| 以 claim / 题目为聚类单位，共 110 个聚类 | 自定（基于数据审计） | 审计结果见 [revision-v2.md](revision-v2.md) §1–§2：NLP 32 条论断、political 17 道题、philpapers 两选项子集 61 个议题。 |

## 3. 评分与偏差控制

| 设计选择 | 依据类型 | 来源与边界 |
|---|---|---|
| 两种选项顺序都评，取平均 | 文献 | D1 摘要识别出位置偏差；D2 摘要写明仅改变顺序就能改变排名，并提出跨顺序聚合。边界：这两篇研究的是「LLM 评估回答质量」，本实验的任务不同，位置偏差的大小要靠本实验的位置诊断来测。 |
| 对立两个答案的长度比限制在 0.8–1.25 | 文献（动机）+ 自定（数值） | D1 摘要识别出冗长偏差，这是控制长度的动机。**0.8–1.25 这个区间没有外部依据**，是自定。 |
| 加长度匹配的对照条件 B0′ | 自定 | 目的：把「加了一段话」和「加了第三方」分开。 |
| 生成答案与评分可能用同一家模型，需要警惕自我偏好 | 文献（动机） | D3 摘要：模型能识别自己的输出，且自我识别越强自我偏好越强。本实验的两个答案由同一生成器写成，对两极是对称的，这降低但不消除风险；这一推理是自定。评分器面板含本地模型，用于复现。 |
| 用 logprobs 读取选择概率 | 待实测 | G1 说明 API 有 `logprobs` 参数；G2 的功能表里**没有**列出 logprobs。必须先用一次真实请求确认现行模型是否返回；若不返回，需要改用多次采样估计概率，设计要相应修订。见 limitations W16。 |

## 4. 统计推断

| 设计选择 | 依据类型 | 来源与边界 |
|---|---|---|
| 以聚类为单位推断，而不是把记录当独立样本 | 文献 | E1：聚类稳健推断的实践指南。 |
| 聚类 bootstrap 区间 | 文献（方法族） | E2 研究聚类误差下的 bootstrap 改进。本仓库的聚类 bootstrap 是该思路的简化版，**并非 E2 的 wild cluster bootstrap-t**。 |
| 聚类符号翻转置换检验作为主检验 | 文献（方法族） | E3 是置换推断的标准来源。本条未读全文，只核验了题录。 |
| 聚类均值上的精确符号检验作为补充 | 自定 | 标准库 `math.comb` 即可复算，对应「不引入 scipy」的可复算性要求。 |
| TOST 等价检验，边界 ±0.05 | 文献（方法）+ 自定（边界） | E4、E5 是 TOST 的来源。**±0.05 没有外部依据**，是自定，须在预注册前由先导结果与实际意义论证。 |
| 目标效应 0.10 | 自定 | 同上，须在预注册前论证。 |
| 样本量与重复数由先导方差导出，只许上调 | 待先导实测 | 现在没有数。V1 的功效数字曾被独立复算证伪（见 [design-revisions.md](design-revisions.md)）。 |
