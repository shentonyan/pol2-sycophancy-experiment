# 产出过程（去标识化摘要）

本文件简述本设计是如何被产出的，使读者能判断其**可靠性来源**。已按去标识化要求处理——**不披露任何作者身份、投票明细或内部辩论**。

---

## 1. 产出方式

本设计由一个**多角色工程流程**产出，而非单一作者撰写：

| 阶段 | 作用 |
|---|---|
| **请求冻结** | 发起人的请求被**逐字冻结**，作为全程不可变的输入 |
| **能力评估** | 每个参与角色**独立签署**自己的任务相关能力评估（含证据）。「我是专家」**从不**作为证据 |
| **并行盲标设计** | 围绕同一冻结输入，**三个**设计独立并行产出；彼此**不可见**；输入**逐字节相同**；结果经**匿名化** |
| **独立评审** | 一个**审计角色**与一个**安全角色**各自独立评审三个设计，未见作者身份 |
| **淘汰/替换** | 按预先规则淘汰或替换 |
| **加权选择** | 对**封存**的作者映射施加**作者回避**的加权投票 |
| **胜出作者修订** | **仅**胜出作者可修订；修订须经**顺序评审**（审计员 → 安全官 → 首席） |
| **作者回避式终投** | 二值终投判定「是否可交付」，**作者不投票**；另有**独立计票复核** |

**关键设计属性**：
- 匿名化映射**封存**，评审者**未开启**
- 评审者的裁决在同行评审后**未被更改**
- 无作者自投，无「幻觉作者投票」
- 无需第三方裁决（无审计/安全裁决分裂）

---

## 2. 为什么本设计要公开自己的撤稿

修订阶段暴露了一处**实质性错误声明**（一款功效数字），经独立复算证伪。

流程**没有**选择悄悄修正它，而是：
1. **完整保留**该错误声明在修订记录中
2. 记录**精确复算值**与**乐观倍数**
3. 把更正后的机制（先导定样本量）写入设计主体
4. 让**四位**独立复算者（作者本人、审计员、安全官、首席）确认同一组数字

同样地，生成调用数的更正方向是**增加成本**，**不利于**设计的便利性。

> **这不是流程的装饰**。它说明该流程产出的工件**能承受对自己声明的复算**——这是本设计唯一能提供的可靠性保证。

## 3. 评审独立性（可外部核验的部分）

| 评审者 | 独立动作（非附和） |
|---|---|
| 审计员 | 用**逐行集合差集**证明**无任何承重设计被削弱**；独立复现**全部 8 行功效表**（$n_{\mathrm{eff}}$ 200→1000，$P^*$ 与功效值吻合到 3 位小数） |
| 安全官 | 独立扫描**全文 1621 行**确认无外部动作词汇；独立复现全部功效表行；另发现被撤稿声明的**命名效应**（$\delta = 0.04$）在 **3200 对观测下仍不可达** |
| 首席 | 在**形成自己的判断之后**才阅读前两份评审；独立用纯整数算术复算功效（拒绝域、$\alpha$、$P=0.52$ 时功效、达 0.80 需的最小 $P$） |

**三者全部 clear，零异议，零退回**（各自退回额度 0/2 未动用）。

## 5. 本文件**不**包含什么

按发布纪律，以下内容**不予披露**：

- 各角色的**投票明细**与计票过程
- **内部辩论**与个别评审的完整意见
- **作者身份**（匿名化映射保持封存）
- 内部**文件路径**、命令、日志、哈希校验细节
- 内部**重试**与运行事件

理由：这些属于流程内部运行信息，其披露会破坏匿名化承诺与评审独立性。

## 6. 一句话总结

> 本设计是一个**经过匿名化并行盲标、独立双向评审、作者回避式加权选择、以及作者回避式终投**的多角色工程产物；其定稿包含**一处公开撤稿**与**一处不利自身的成本更正**，两者均经**四方独立复算**确认。
